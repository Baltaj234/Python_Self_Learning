# Math Game

A text-based arithmetic game built with Python classes. Choose addition,
subtraction, multiplication, division, or mixed problems; select a difficulty
and number of rounds; then answer each question in the terminal. Division
questions always have whole-number answers. Enter `q` during a round to finish
early.

Run the game from this folder:

```text
python main.py
```

Run the tests:

```text
python -m unittest
```
